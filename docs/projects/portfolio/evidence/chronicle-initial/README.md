# Chronicle initial implementation — captured evidence

Captured before the user's landscape/glass refinement request was implemented.
These are actual browser captures of the initial AI-assisted production components,
not reconstructions or screenshots of the design-reference images.

- Six viewport captures: populated draft homepage, portfolio detail and public
  header/home at desktop 1440 × 900 and mobile 390 × 844.
- Two full-page homepage captures preserve the initial excessive vertical extent.
- `capture-manifest.json` records capture time, routes, viewport sizes, document
  heights and the reduced-motion setting used for stable frames.
- Five `.snapshot.txt` files preserve the initial theme stylesheet, tokens,
  selection, homepage and case-study composition. This is a partial source
  snapshot, not a complete repository checkout.

This archive documents the first implementation's limitations: vertical page flow,
underdeveloped framing and controls, and loose correspondence with the approved
Chronicle reference. It can support a later case-study comparison explaining how
directed review and revisions changed the finished interface. Do not label it as
the finished Chronicle design or replace these captures with newer ones.
